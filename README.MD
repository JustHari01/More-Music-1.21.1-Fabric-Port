# More Music (UNOFFICIAL)
A client-side Fabric port for Minecraft 1.21.1 that lets you shorten and configure the wait between music tracks. Set separate minimum and maximum delays for the main menu, normal gameplay, Creative mode, and the End. Each category defaults to 20–40 ticks. The normal-gameplay delay also applies to music entries created by data packs.

## Compatibility and configuration

Requires Minecraft 1.21.1, Fabric Loader 0.16.14 or newer, Fabric API, and Cloth Config API. Mod Menu 11.0.5 or newer is optional. Open the settings from the Sound Options screen or Mod Menu.

The upstream project is [More Music](https://modrinth.com/mod/moremusic), with source at [arthomnix/moremusic](https://github.com/arthomnix/moremusic).
