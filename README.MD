# More Music
A Fabric client mod that lets you configure the delay between Minecraft music tracks. The default delay is short, so music plays more often, and can be changed in the configuration screen.

## Unofficial Fabric 1.21.1 port

This community port targets Minecraft 1.21.1 on Fabric and preserves the upstream controls for main menu, normal gameplay, creative mode, and End music. Minimum and maximum delays are configured in ticks. The options screen remains available from the Sound Options menu and through Mod Menu.

Requires Fabric API and Cloth Config API. Mod Menu is optional but recommended for configuration.

This project is an unofficial port by JustHari01 and is not affiliated with or endorsed by arthomnix. The upstream project is [More Music](https://modrinth.com/mod/moremusic), with source at [arthomnix/moremusic](https://github.com/arthomnix/moremusic).
